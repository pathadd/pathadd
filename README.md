# Pathadd

A restrained, local-first web toolkit and browser extension suite built for people who care about control over their content.

**Zero ads. Zero tracking scripts. Zero server uploads.** Everything runs client-side in your browser with minimal permissions.

## Chrome Extension (Approved in 3 Hours on First Submission)

- **[Pathadd — Markdown to Word](https://chromewebstore.google.com/detail/pathadd-%E2%80%94-markdown-to-wor/gllomoipeokhaggeeocbnncojigfmbip)** ([Open-Source Repo](https://github.com/pathadd/markdown-to-word-extension))  
  Approved on the Chrome Web Store in **3 hours** on our very first submission—built with Manifest V3, zero remote scripts, and strict client-side execution. Converts Markdown and AI responses (ChatGPT / Claude) with native editable Word equations (OMML), matrices, tables, and Mermaid diagrams into real `.docx` files.

## Web Tools ([pathadd.com/en/](https://pathadd.com/en/))

- **Markdown / AI to Word** — Turn Markdown and AI drafts into real `.docx` documents with native OMML equations and crisp Mermaid diagrams without Pandoc or backend uploads.
- **Redacted AI Context Packer** — Pack local folders/files with token estimates while masking API keys and internal IPs before anything reaches an AI prompt.
- **Geek Communication (E2EE & Time-Locked Messaging)** — End-to-end encrypted, identity-bound, and time-locked message delivery with client-side key derivation.
- **Log Redaction & Everyday Utilities** — Ad-free JSON formatter, text diff, character encoding, and browser crypto tools.
