# Pathadd

A restrained, local-first web toolkit and browser extension suite built for people who care about control over their content.

Everything runs client-side in your browser—zero server uploads, no account walls, and minimal permissions.

## Chrome Extension

- **[Pathadd — Markdown to Word](https://chromewebstore.google.com/detail/pathadd-%E2%80%94-markdown-to-wor/gllomoipeokhaggeeocbnncojigfmbip)**  
  Convert Markdown and AI responses (ChatGPT / Claude) with native editable Word equations (OMML), matrices, tables, and Mermaid diagrams into real `.docx` files directly in the browser.

## Web Tools ([pathadd.com/en/](https://pathadd.com/en/))

- **Markdown / AI to Word** — Turn Markdown and AI drafts into real `.docx` documents with native OMML equations and crisp Mermaid diagrams without Pandoc or backend uploads.
- **Redacted AI Context Packer** — Pack local folders/files with token estimates while masking API keys and internal IPs before anything reaches an AI prompt.
- **Geek Communication (E2EE & Time-Locked Messaging)** — End-to-end encrypted, identity-bound, and time-locked message delivery with client-side key derivation.
- **Log Redaction & Everyday Utilities** — Client-side log sanitization, text diff, encoding, JSON formatting, and browser crypto tools.
